### 1. Abrir la Plataforma Web Completa

Dentro de la plataforma tienes **5 módulos conectados entre sí**:
1. **🌐 1. Web & Portafolio:** Página oficial persuasiva con galería de proyectos (*Antes / Propuesta 3D / Plano*) y botón para subir tus propias fotos improvisadas de obra.

Cotizador + Metrado:** Calcula al instante el precio según los $\text{m}^2$, niveles y departamento del Perú, aplicando automáticamente la regla geográfica (**Planos en todo el Perú** vs. **Remodelación física en Lima** vs. **Pack Remodelación a Distancia para Provincias**) e incluyendo un **Pre-Metrado Anti-Engaño** (bolsas de cemento, ladrillos, fierro).

4. **🎬 4. Fábrica TikTok/IG (Estudio 9:16 en Vivo):** Sube cualquier foto improvisada de obra o plano y el sistema crea en vivo un **video vertical 9:16 animado (`.webm`)** con gancho viral, subtítulos y llamado a la acción listo para descargar, además de darte el guion segundo a segundo y el calendario de 30 días.
5. **🔒 5. CRM, Pagos & Marca de Agua:**

## 🤖 Uso del Automatizador en Python (`automatizador_gio.py`)

Si agregas nuevas fotos o videos improvisados dentro de la carpeta `mis_fotos_y_videos/`, ejecuta:

```powershell
python automatizador_gio.py --scan
```

Esto actualizará automáticamente:
- `data/PLAN_PUBLICACION_LISTO.md` (Guiones de TikTok/Reels para cada archivo nuevo).
- `data/reporte_ejecutivo_gio.json` (Reporte comercial y simulaciones de cobro).

Para levantar el servidor web local en cualquier momento:

```powershell
python automatizador_gio.py --serve --port 8080
```
