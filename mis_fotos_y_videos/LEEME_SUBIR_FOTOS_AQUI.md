# 📸 Carpeta Cloud de Fotos y Videos — Planos Gio

Cualquier foto (`.jpg`, `.png`, `.webp`) o video (`.mp4`, `.mov`, `.webm`) que se agregue a esta carpeta (incluso subiéndolo desde tu celular directamente en GitHub con tu PC apagada) activará automáticamente el servidor en la nube (**GitHub Actions**) para actualizar el portafolio y los guiones de TikTok/Instagram.
